# CardImagePlacement

Specifies the placement of the image in the `HxCard` component.

## Enum values

| Name | Value | Description |
|------|-------|-------------|
| Top | 0 | Image before the body (`card-img-top`). In a horizontal card (`HxCard.Horizontal`), the image is placed at the (inline) start of the card (`card-img-start`). |
| Bottom | 1 | Image after the body (`card-img-bottom`). In a horizontal card (`HxCard.Horizontal`), the image is placed at the (inline) end of the card (`card-img-end`). |
| Overlay | 2 | Image as a card background, the body is rendered as an overlay (`card-img-overlay`). |
