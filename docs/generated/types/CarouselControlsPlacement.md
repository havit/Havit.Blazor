# CarouselControlsPlacement

Placement of the `HxCarousel` controls (previous/next, play/pause) and indicators relative to the slides. Does not apply to `HxCarousel.Overlay` carousels.

## Enum values

| Name | Value | Description |
|------|-------|-------------|
| Bottom | 0 | Controls are rendered below the slides (default). |
| Top | 1 | Controls are rendered above the slides. |
