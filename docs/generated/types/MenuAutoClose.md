# MenuAutoClose

Auto-close behavior of the `HxMenu` (`HxMenuToggleButton` respectively). The `Esc` key always closes the menu, regardless of the auto-close behavior. .

## Enum values

| Name | Value | Description |
|------|-------|-------------|
| True | 0 | The menu will be closed by clicking outside or inside the menu. Default. |
| False | 1 | The menu will be closed (only) by clicking the toggle button (or by pressing the `Esc` key). |
| Inside | 2 | The menu will be closed (only) by clicking inside the menu. |
| Outside | 3 | The menu will be closed (only) by clicking outside the menu. |
