# NavVariant

Variations for `HxNav`.

## Enum values

| Name | Value | Description |
|------|-------|-------------|
| Standard | 0 | Base `nav`. |
| Tabs | 1 | Tabs. https://v6-dev--twbs-bootstrap.netlify.app/docs/6.0/components/nav/#tabs Remember to set the `active` tab (`HxNavLink.CssClass`). |
| Pills | 2 | Pills https://v6-dev--twbs-bootstrap.netlify.app/docs/6.0/components/nav/#pills. |
| Underline | 3 | Underline https://v6-dev--twbs-bootstrap.netlify.app/docs/6.0/components/nav/#underline. |
