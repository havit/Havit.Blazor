# PlaceholderAnimation

Animation of the placeholders (for `HxPlaceholderContainer.Animation`).

## Enum values

| Name | Value | Description |
|------|-------|-------------|
| None | 0 | No animation. |
| Pulse | 1 | Opacity pulse animation (`.placeholder-pulse`). |
| Glow | 1 | Animation with a glowing effect. Bootstrap 6 keeps `.placeholder-glow` only as a compatibility alias of `.placeholder-pulse`. |
| Wave | 2 | Animation with a waving effect (`.placeholder-wave`). The Bootstrap 6 default loading animation. |
